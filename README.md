# Swapnil Sutar — 3D Application Support Portfolio

A responsive, dark blue production-operations portfolio built to follow the supplied reference layout: cinematic hero, incident-response cards, capability tiles, global-support visual, experience cards, achievements, certification, and contact details.

## Run
Open `index.html` in a modern browser. No build step or framework is required. The resume PDF is included in `assets/` and linked from the header and footer.

## Content accuracy
Experience, technologies, education, certification and achievements are based on the supplied resume. Incident timeline timestamps are explicitly illustrative and are not presented as a real incident record. The global support illustration is decorative.
